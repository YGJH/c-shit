### **線性插值（Linear Interpolation, LERP）**
線性插值是一種數值方法，**用來在已知數據點之間估算未知值**。  
當我們有兩個已知點 \((x_0, y_0)\) 和 \((x_1, y_1)\)，我們可以用線性函數來估算介於這兩點之間的值。

---

## **1. 數學公式**
給定兩個點 \((x_0, y_0)\) 和 \((x_1, y_1)\)，對於一個新點 \( x \)（滿足 \( x_0 \leq x \leq x_1 \)），我們使用下面的公式來計算對應的 \( y \) 值：

\[
y = y_0 + \frac{(y_1 - y_0)}{(x_1 - x_0)} \times (x - x_0)
\]

這個公式的幾何意義是找到 **通過這兩個點的直線的方程式**，然後計算 \( x \) 對應的 \( y \) 值。

---

## **2. 線性插值的 C++ / Python 實現**
### **C++ 版**
```cpp
#include <iostream>

double linearInterpolation(double x0, double y0, double x1, double y1, double x) {
    return y0 + (y1 - y0) * (x - x0) / (x1 - x0);
}

int main() {
    double x0 = 1, y0 = 2;
    double x1 = 3, y1 = 10;
    double x = 2; // 要插值的 x
    double y = linearInterpolation(x0, y0, x1, y1, x);
    
    std::cout << "插值結果 y = " << y << std::endl; // 預期結果: y = 6
    return 0;
}
```

### **Python 版**
```python
def linear_interpolation(x0, y0, x1, y1, x):
    return y0 + (y1 - y0) * (x - x0) / (x1 - x0)

# 測試
x0, y0 = 1, 2
x1, y1 = 3, 10
x = 2
y = linear_interpolation(x0, y0, x1, y1, x)

print(f"插值結果 y = {y}")  # 預期結果: y = 6
```

---

## **3. 幾何意義**
線性插值可以看作是在 **兩點之間做線性變化**：
- 當 \( x = x_0 \) 時，\( y = y_0 \)
- 當 \( x = x_1 \) 時，\( y = y_1 \)
- 介於兩者之間時，\( y \) 是沿著這條直線變化的中間值。

---

## **4. 應用**
### **(1) 圖形與動畫**
- 在 **計算機圖形學**（如遊戲開發）中，**線性插值（LERP）** 用來在 **兩個顏色、位置或數值之間平滑過渡**。
- 例如，當你要讓一個角色從 \( (x_0, y_0) \) 平滑移動到 \( (x_1, y_1) \) 時，會使用線性插值來計算中間幀的位置。

### **(2) 音頻處理**
- 在 **數字音頻** 中，當我們想要在兩個離散的音頻樣本之間估算值時，線性插值可以用來**平滑音頻信號**。

### **(3) 資料科學 & 機器學習**
- 當有缺失數據時，可以用線性插值來填補缺失值。

---

## **5. 與其他插值方法的比較**
| 方法 | 說明 | 優點 | 缺點 |
|------|------|------|------|
| **線性插值** | 使用兩點之間的直線來估算 | 計算快、簡單 | 只能產生直線，無法擬合曲線 |
| **多項式插值（Polynomial Interpolation）** | 使用高次多項式來擬合 | 能夠適應彎曲的數據 | 可能過擬合，數值不穩定 |
| **樣條插值（Spline Interpolation）** | 使用一系列光滑的曲線段來連接數據點 | 平滑度較好，能擬合曲線 | 計算較複雜 |

---

## **6. 結論**
- **線性插值（LERP）是最簡單的插值方法**，主要用來估算兩個已知點之間的值。
- **適用於快速計算，但不適合處理非線性數據**（如曲線）。
- 在 **遊戲、動畫、數據補全、音頻處理** 等領域應用廣泛。
